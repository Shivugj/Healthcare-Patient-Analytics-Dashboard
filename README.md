📊 Healthcare Patient Analytics Dashboard | Power BI Project
Excited to share my latest Healthcare Patient Analytics Dashboard built in Power BI.
This dashboard provides insights into:
 ✅ Patient Distribution by Bed Grade
 ✅ Patients by Age Group
 ✅ Average Deposit Analysis by Length of Stay
 ✅ Severity Distribution Across Age Groups
 ✅ Patient Admissions by Admission Type
 ✅ Department-wise Severity Analysis
 ✅ Ward-wise Patient Summary
Key Insights:
 🔹 Age Group 41–50 has the highest patient count
 🔹 Emergency admissions contribute a major share of admissions
 🔹 Moderate severity cases account for a significant portion of patients
 🔹 Patient deposits vary based on severity and length of stay
 🔹 Department-wise analysis helps identify patient load and resource utilization
Tools Used:
 🔹 Power BI
 🔹 Power Query
 🔹 DAX
 🔹 Data Modeling
 🔹 Excel
This project helped me strengthen my skills in data cleaning, modeling, visualization, and business insight generation.
